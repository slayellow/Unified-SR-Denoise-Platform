## 5 판정 (Decision)
HYP-09 **부분 지지**, 채택 아님 (G3 cam92 5.44 % > 5.0 %, cam98 6.68 % > 5.8 %, G2 cam92 0.937 < 0.95로 근소 미달). EXP-06-1 대비 오버슈트 7.40 → 5.44 %, 1/4v 11.9 → 5.4로 남은 두 미달이 거의 풀렸지만, 대각 1/4d 3.8 → 24.6(목표 안), 1/2h 4.7 → 75.6(보고 항목)으로 늘고 격자 제외 선명도 1.216 → 1.171로 낮아졌다. 06-1(더 선명, 링잉 7.4 %)과 09-1(더 깨끗, 덜 선명)이 두 후보 — 게이트 경계값은 소유자 보드 판정으로 보정한다.
